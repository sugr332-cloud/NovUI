この作品の本文は、ノベルゲームの台本の形式で書かれています。本文は次のように読んでください。

* `<!-- scene: S1 -->` は場面の区切り、`@` で始まる行は演出の指示です（`@bg` 背景、`@enter`・`@exit` 人物の登場と退場、`@face` 表情の変更、`@choice` と続く `- 文 -> 場面 ID` の行は選択肢、`@goto` は合流先への移動）。演出の指示の行は本文ではありません。
* `<表示名>「…」` は台詞、`<表示名>（…）` は心の声、`［…］` はそのときの表情です。それ以外の行は地の文です。台詞の話者は行の頭の表示名で確定しています（表示名と人物 ID の対応は、場面ごとの人物の規則の display_name を見てください）。表示名が人物でない行は、名前のない端役の台詞です。
* `@if <フラグ>`（または `@if not <フラグ>`）から `@else` までと、`@else` から `@endif` までは、フラグによってどちらか一方だけが表示される行です。両方を、それぞれの場合の本文として読んでください（両方が続けて表示されるものとして矛盾を指摘しないでください）。
* 人物の規則の値（呼び方・関係）が、1つの値ではなく `{value, flags}` の並びになっていることがあります。これは、それまでの選択肢で立ったフラグによって値が違うことを示します（例：`{value: 君, flags: {market_together: true}}` は、market_together が立っていれば「君」）。`@if <フラグ>` の中ではそのフラグが立っている行、`@else` の中（`@if not <フラグ>` の中）では立っていない行の値と照合してください。`@if` の外で、並んだ値のうち一部の場合にしか正しくない値を使っていれば、character の指摘にしてください（どの場合にも正しい表現にするか、`@if` で書き分ける必要があります）。値が `{default, changes}` の形のときは、changes の when（フラグの条件）と from（変わる位置）から判断してください。
* knowledge の項目に when があるものは、そのフラグの条件が成り立つ場合だけ人物が知っていることです。`@if` の中と外で、上と同じように扱ってください。伏線の状況の位置に when があるものも、その条件の場合だけ張られた（進んだ）ものです。
* 選択肢があると、プレイヤーの選んだ方の場面だけを通ります。行き先の場面は、選ばれた場合だけ表示されます。
* 場面の最後に `@choice` も `@goto` も無い場面は、ファイルの中で次の場面へそのまま進みます（最後の場面なら章の終わり）。`@goto` が無いことは、合流しないという意味ではありません。
* 演出の指示の行の誤り（登録の無い表情、登場していない人物の台詞、背景など）は Controller が機械検査で調べます。重ねて指摘しなくてかまいません。
* anchor の text には、本文の行をそのまま抜き出してください（表示名・表情・括弧を含めてよい）。演出の指示の行は anchor にしないでください。
