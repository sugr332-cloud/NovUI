■ この章の分岐

この章には、選択肢によって通る道と通らない道がある場面（分岐の場面）や、フラグで書き分けた行（`@if`）があります。分岐の場面と、その場面を通る道で必ず成り立つフラグの条件は次のとおりです（条件なしの場面は、フラグで区別できない場面です）。

{{branch_scenes}}

* events には、どの道を通っても起きる出来事だけを書いてください。
* 分岐の場面だけで起きた出来事と、`@if`・`@else` の中だけで起きた出来事は、branches に書いてください。branches の各件は次のとおりです。
  - scenes：出来事が起きた場面の ID の配列。
  - when：その道の条件。分岐の場面なら上の条件のうち1つ、`@if <フラグ>` の中なら `<フラグ>`、`@else` の中なら `not <フラグ>`。条件なしの場面なら null。
  - events：出来事を起きた順に1件1文で。場面の ID を文頭に書いてください。
* characters と foreshadowing は、どの道の出来事かにかかわらず今までどおり書いてください（道ごとの条件は、この後の設定ファイルの変更の提案で付けます）。
