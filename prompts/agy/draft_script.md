章 {{chapter_id}} の台本を、ノベルゲームの台本の形式で書いてください。

上の資料のうち、chapters/{{chapter_id}}/plan.yaml がこの章の執筆計画、chapters/{{chapter_id}}/outline.md が Human の書いた章の概要です。plan の pov（視点）、style_notes（文体の注意）、scenes（場面の構成）、prohibitions（書いてはいけないこと）、connection（前の章・次の章とのつながり）に従ってください。outline と plan にない出来事を加えてはいけません。

{{script_format}}

書き方の決まり：

* 場面は plan の scenes の順に、{{scene_ids}} の {{scene_count}} 場面を書いてください。場面を増やしたり、減らしたり、順番を変えたりしてはいけません。各場面の先頭に、その場面の区切りの行を1行だけ置いてください。
* 場面のつながりと背景は次のとおりです。各場面の最後の行は、選択肢のある場面は `@choice` と選択肢の行（文・行き先・フラグを下のとおりに、同じ順で）、`@goto` と書いた場面は `@goto` の行にしてください。どちらでもない場面には、`@choice` も `@goto` も書かないでください。

{{scene_flow}}

* 場面の始まりでは、画面に誰もいません。話す人物は、話す前に `@enter` で登場させてください（画面の外からの声にするときだけ、登場させずに台詞を書きます）。同じ位置に2人を出さないでください。
* 人物 ID・表示名・使える表情・台詞と呼び方は、次の「場面ごとの人物の規則」に従ってください。表示名は表の display_name、表情は表の expressions にあるものだけを使ってください。表情は変えるときだけ書けば、次に変えるまで続きます。値は、その場面の時点で有効なものです（場面によって呼び方が変わる人物がいます）。suspended_rules に挙がっている規則は、その場面では従わなくてかまいません。address に相手が無い場合は default を使ってください。knowledge に無いことを、その人物が知っているように書いてはいけません。

* 名前のない端役に台詞を言わせてよいのは、次の場面の、次の名前の端役だけです（表示名としてそのまま使い、`@enter` はしません）。それ以外の名前のない人物の言葉は、地の文で書いてください。

{{extras}}

* 台本の長さは、台詞・心の声・地の文の本文だけを数えて（`@` の行、場面の区切り、表示名、表情は数えない）、空白と改行を除いて {{min_chars}} 字以上 {{max_chars}} 字以下にしてください。
* 資料にない設定が必要になった場合は、推測で決めずに、その箇所に【要確認：何が不明か】と書いてください（地の文の行として書きます）。
* 台本の前後に、説明や見出しを書かないでください。
