# Phase 3-A 修正 01 作業報告

## 実装・修正したもの

1. **R1：NovUI-Edit で安全でないパスの違反が消える不具合の修正**
   - `src/novui/protectaudit.py`:
     - `audit_changes` の規則 3 において、`NovUI-Edit` trailer がある場合に `return []` していた箇所を `return violations` に修正。規則 1 で検出された安全でないパス（`unsafe path`）の違反が適切に返るように改善。
   - `tests/test_protectaudit.py`:
     - `test_rule3_allow_edit_with_unsafe_path` を追加し、`NovUI-Edit` 付きで安全でないパスを含む変更が正しく違反として検出されることを確認。

2. **R2：作業ブランチに要確認を書いた際に承認待ち state_update 提案が無効になる問題の修正**
   - `src/novui/chapters.py`:
     - `review_only_since(repo: Path, base: str, head: str, chapter_id: str) -> bool` を追加。
       `base` が `head` の祖先であり（`base == head` 含む）、`base..head` の全 commit が merge commit でなく、`chapters/<chapter_id>/chapter.yaml` の M 変更のみであり、親と比べて `review_required` と `review_reasons` 以外のキーの値が等しいことを判定。
   - `src/novui/stateupdate.py`:
     - `approve_state` の「復旧の判定」における `parent == proposal["branch_head"]` を `review_only_since(worktree, proposal["branch_head"], parent, chapter_id)` に変更。
     - `approve_state` の「無効の検査」における `head != proposal["branch_head"]` を `not review_only_since(worktree, proposal["branch_head"], head, chapter_id)` に変更。
   - `tests/test_review_required.py`:
     - `test_review_only_since_unit` を追加し、要確認 commit のみ（1件、2件）での True、state 変更や別ファイル変更、非祖先での False を検証。
     - `test_approve_state_with_review_required` を追加し、state_update 提案が承認待ちの章に `mark_review_required` で要確認を立てた後、および `clear_review_required` を実行した後のいずれでも、提案が invalid にならずに正常に承認（`HUMAN_APPROVED`）できることを検証。
