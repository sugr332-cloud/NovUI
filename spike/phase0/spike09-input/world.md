# 世界観設定（World）

## 舞台
- **鉱山街アルト**:
  大陸東部、ガルダ帝国領の辺境に位置する古い鉱山街。
  かつては豊富な鉱石を産出したが、現在は枯渇し、貧しい鉱夫と孤児が身を寄せ合って暮らしている。
  常に煙突から煤煙が漂い、錆びた鉄と泥の匂いが街を覆っている。

## キーアイテム・事象
- **蒼天晶（そうてんしょう）**:
  失われた古代神代の遺産とされる青い結晶。
  所持者の生命力や意志に呼応して物理的な力場や衝撃波を発生させる。
  帝国では禁忌指定されており、発見者は極刑、結晶は直ちに回収されることになっている。

- **帝国特務執行局**:
  帝都直属の冷酷な秘密警察。全身黒尽くめのコートと鉄仮面を着用し、禁忌結晶の探索と回収を行っている。
