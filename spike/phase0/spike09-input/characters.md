# キャラクター設定（Characters）

## ルカ（Luka）- 主人公
- **年齢**: 16歳 / 男性
- **立場**: 街の廃鉱で屑拾いをして暮らす孤児。
- **性格**: 慎重で口数は少ないが、仲間に対する義理堅さと強い芯を持つ。過酷な環境で育ったため現実主義。
- **口調**: 「……分かってる」「俺一人ならどうとでもなるが、お前を巻き込むわけにはいかない」

## エナ（Ena）- ヒロイン
- **年齢**: 15歳 / 女性
- **立場**: 亡き両親の遺した小さなパン屋を一人で切り盛りする少女。ルカの唯一の理解者。
- **性格**: 芯が強く健気。ルカが無茶をすることを誰よりも心配している。
- **口調**: 「ルカ、またそんな危ない場所へ行ったの？」「お願いだから、無茶だけはしないで」

## ヴォルク執行官（Volk）
- **立場**: 帝国特務執行局の小隊長。
- **性格**: 徹底的な冷徹漢。任務のためなら罪のない市民の犠牲も厭わない。
- **口調**: 「反逆者に告ぐ。蒼天晶を差し出し、首を垂れよ」
