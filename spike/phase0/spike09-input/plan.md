# 第1章 執筆計画（Plan）

## 目標字数
4,000〜5,000字

## シーン構成

### シーン1：旧鉱道の採掘跡
- **登場人物**: ルカ
- **状況**: 夕暮れ前、雨が降り始める直前のじめついた空気。
- **行動**: ルカが廃坑で鉱石を探している際、崩れた瓦礫の中から淡く青く脈動する石（蒼天晶）を発見する。
- **感情・描写**: 孤独感と、石に手を触れたときの冷たさと相反する奇妙な温もり。

### シーン2：エナのパン屋と不穏な影
- **登場人物**: ルカ、エナ
- **状況**: 街の裏通りにある小さなパン屋。雨が降り始める。
- **行動**: ルカはエナに石を見せようとするが、街の通りに黒衣の帝国軍特務執行官たちが歩いているのを目撃する。
- **対話**: エナは不吉な予感からルカに「その石を捨てて」と懇願するが、執行官の足音が店に近づく。

### シーン3：急襲と覚醒、雨中の逃走
- **登場人物**: ルカ、エナ、帝国執行官
- **状況**: 夜、激しい土砂降りの雨。
- **行動**: 執行官が店に踏み込み、エナを脅迫して石の在処を問いただす。隠れていたルカが飛び出し、石を握りしめると青い衝撃波が放たれ、兵士を吹き飛ばす。
- **結末**: ルカはエナの手を引き、追っ手を振り切りながら夜の山道へと駆け出す。
